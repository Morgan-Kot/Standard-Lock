Standard-Lock

A small encryption project for people who want to experiment with, create, and share their own encryption methods.

About the project

Standard-Lock isn't intended to replace established cryptography. The project is designed for lightweight personal use, experimentation, and learning how encryption algorithms can be built and modified.

The architecture is intentionally simple: encryption and decryption methods can be added, edited, or removed without rebuilding the whole concept around a single fixed cipher.

How it's made

The project is written in Python, with individual methods kept in their own folders. This makes it easy to experiment with a method without changing unrelated methods.

This website provides browser-friendly JavaScript equivalents for methods that have a Try it! demo.
